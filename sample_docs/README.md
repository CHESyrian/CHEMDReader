# Welcome to CHEMDReader

This is a small sample workspace to help you explore the reader. Set `ROOT_DIR` to your own documentation folder when you are ready.

## A calm place for technical notes

CHEMDReader keeps the interface out of the way so the content can take center stage. Try the **Open local folder** button to browse a folder directly in your browser.
